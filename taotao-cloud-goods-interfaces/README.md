buyer
├─ common      ✅ 四端(app/h5/web/mini)共用接口
├─ app         ✅ 原生安卓、iOS App
├─ h5          ✅ 手机H5、公众号内嵌网页、App内网页
├─ web         ✅ PC浏览器商城网页
└─ mini        ✅ 微信/支付宝/抖音/百度/快手小程序

buyer 买家侧，后端控制器渠道标识只需要维护 **4 个核心**：

| 标识 | 全称 | 说明 |
|---|---|---|
|app | 移动端原生 App|Android /iOS|
|h5 | 移动端 H5 网页 | 手机浏览器、公众号网页、内嵌 H5|
|web|PC 网页端 | 电脑浏览器商城主页 |
|mini | 小程序端 | 微信 / 支付宝 / 抖音 / 百度小程序等 |

场景	归属目录	原因

公众号网页 (H5 页面)	h5	只是在微信浏览器打开，本质就是 H5

鸿蒙元服务	mini	和小程序逻辑相近，复用 mini 接口即可

平板浏览器访问商城	h5 / web	浏览器，不是独立客户端

Electron 桌面客户端 exe	web	请求完全复用 PC‑web 接口

车载大屏 / 电视商城	h5/web	浏览器内核，无需独立一套接口

App 内嵌网页	h5	内嵌网页走 H5 接口
